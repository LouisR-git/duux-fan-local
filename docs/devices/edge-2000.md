# Duux Edge 2000 (Heater)

Local control specifications and supported features for the **Duux Edge 2000** convector heater (model DXCH15, firmware 14.3.10).

The heater connects to `collector3.cloudgarden.nl` on port `443` and reports itself on `sensor/{device_id}/update` as `{"pid":"oryf2o5f8wmaeaav","tune":"Edge heater"}`.

## Supported Features

| Feature | Key | Command Payload | Value / Range |
|---|---|---|---|
| **Power** | `power` | `tune set power X` | `0`: off, `1`: on |
| **Set Target Temperature** | `sp` | `tune set sp X` | `5` to `36` °C (step 1) |
| **Current Temperature** | `temp` | N/A (climate) | °C |
| **Timer** | `timer` | `tune set timer X` | `0` to `12` hours |
| **Timer Remaining** | `timRm` | N/A (sensor) | minutes (key appears after the first power on) |
| **Night Mode** | `night` | `tune set night X` | `0`: off, `1`: on |
| **Child Lock** | `lock` | `tune set lock X` | `0`: off, `1`: on |

Also reported, but not exposed:

| Key | Command Payload | Meaning |
|---|---|---|
| `mode` | `tune set mode X` | `0`: thermostat (holds `sp`), `1`: weekly program (calendar icon on the display; switching to it sets `timer` to `0`). `2` is ignored. |
| `eco` | `tune set eco X` | `0` to `3`. Follows `sp` and `mode`; the display shows no matching setting, so it looks like an internal state. |
| `status` | N/A | `1` when off, `0` when on |
| `err` | N/A | always `1` so far |

`mode` and `eco` were checked against the heater's display on firmware 14.3.10.

## Home Assistant Entities

- **Climate**: Off/Heat, target temperature (5 °C to 36 °C, step 1), current temperature.
- **Switch**: Night Mode, Child Lock.
- **Number**: Timer (`0` to `12` hours).
- **Sensor**: Timer Remaining (minutes).
